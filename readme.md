## 🇷🇺 Русский

**BadLaunch** — это быстрый, легкий и удобный лаунчер для Minecraft, который поддерживает огромный спектр версий: от классической **1.19.4** до новейшей **26.3**.

### ✨ Главные особенности:
*   **Поддержка популярных загрузчиков:** Из коробки доступны Vanilla, **Fabric**, **Forge** и **NeoForge**. Список версий загрузчиков автоматически фильтруется под выбранную вами версию игры.
*   **Молниеносная загрузка:** Благодаря параллельному скачиванию в 16 потоков и кешированию, установка игры занимает минуты, а повторные запуски происходят за считанные секунды.
*   **Гибкая настройка папок:** Выбирайте, как хранить файлы игр: в одной общей папке, в отдельной для каждой версии, или сгруппировать их (1.19+, 1.20+, 1.21+ и т.д.).
*   **Современный интерфейс:** Приятный глазу дизайн с поддержкой тем (тёмная, светлая, кастомная) и настройкой акцентного цвета.
*   **Чистота и порядок:** Лаунчер не затрагивает файлы официального клиента и хранит все данные в изолированной папке.

### ⚙️ Системные требования:
*   **ОС:** Windows 10 / 11 (64-bit)
*   **Java:** Обязательно должна быть установлена (Java 17 для старых версий, Java 21 для 1.20.5+ и Java 25 для 26.x).

> 💡 **Установка не требуется:** Просто скачайте `Badlaunch.exe`, положите в любую удобную папку и запустите.

## 🇬🇧 English

**BadLaunch** is a fast, lightweight, and user-friendly Minecraft launcher that supports a huge range of versions: from classic **1.19.4** to the latest **26.3**.

### ✨ Key Features:
*   **Popular mod loaders support:** Vanilla, **Fabric**, **Forge**, and **NeoForge** are available out of the box. The loader version list is automatically filtered based on the selected game version.
*   **Lightning-fast downloads:** Thanks to parallel downloading (16 threads) and caching, game installation takes minutes, and subsequent launches take seconds.
*   **Flexible folder management:** Choose how to store game files: in a single shared folder, a separate one for each version, or grouped (1.19+, 1.20+, 1.21+, etc.).
*   **Modern UI:** A sleek design with theme support (dark, light, custom) and customizable accent colors.
*   **Clean and isolated:** The launcher does not touch official client files and stores all data in an isolated directory.

### ⚙️ System Requirements:
*   **OS:** Windows 10 / 11 (64-bit)
*   **Java:** Must be installed (Java 17 for older versions, Java 21 for 1.20.5+, and Java 25 for 26.x).

> 💡 **No installation required:** Just download `Badlaunch.exe`, place it in any folder, and run it.
